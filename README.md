# Mythos and Stories

## FUN FICTION & CAUTIONARY SCI-FI

This repository contains fun, imaginative science-fiction stories that warn about the perils of coercive control structures. It contains zero serious scientific claims.

## Scope

- Creative fiction books
- Musical Universe stories and narrative material
- Dreamscape Translator fiction
- Narrative portions of Miniverse
- Cautionary speculative stories about agency, autonomy, and coercive systems

This is fiction. It is not a scientific repository and its stories are not hypotheses.

## Migration standard

Narrative material from the former mixed project can be rewritten, reorganized, split, or consolidated where necessary while preserving the story, themes, and creative intent.
